# PixelClean — Usage Examples

## 1. Image Watermark Removal
To test image watermark removal:
1. Navigate to `http://localhost:3000/image`.
2. Drag and drop any image generated by Google Gemini or Imagen.
3. Choose the removal intensity and export format (PNG, JPEG, WebP).
4. Click **Download** to save the clean image locally.

## 2. Video Watermark Removal & Looping
To test video watermark removal and looping:
1. Navigate to `http://localhost:3000/video`.
2. Upload a short video clip containing a watermark.
3. Select an export resolution (1080p HD, 1440p 2K, or 2160p 4K).
4. (Optional) Set Target Duration (e.g., 10 minutes) to loop the clip seamlessly.
5. Click **Start Processing** and monitor real-time frame progression.
